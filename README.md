# Jacky Kumar — Personal Research Website

Static academic website adapted for Jacky Kumar from the supplied website template.

## Main content
Most profile content lives in `assets/data/site.js`. Edit that file to update projects, publications, experience, news, links, and contact details.

## Before publishing
1. Replace `assets/img/profile.svg` with your own portrait (or update the image path in `index.html` and `about.html`).
2. Add your email, Google Scholar, INSPIRE, LinkedIn, and CV links in `assets/data/site.js`.
3. Review publication titles/authors and add your full publication list.
